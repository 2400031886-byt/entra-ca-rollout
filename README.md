# Entra CA Rollout

A web-based Microsoft Entra Conditional Access Rollout System designed to manage and visualize access policies, authentication workflows, and risk evaluation.

## 🚀 Features

- User Login
- Multi-Factor Authentication (MFA)
- Conditional Access Policy Management
- Risk Evaluation
- User Dashboard
- Policy Data Management
- Responsive Web Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- JSON
